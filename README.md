## 📌 What is Image-Paster?

Image-Paster acts as a background manager for your clipboard. When you copy an image to your clipboard on Windows, the operating system keeps only the most recent item. If you copy a new image or text, the previous image disappears. Image-Paster prevents this data loss by capturing every image you copy. It saves these images into a history folder on your computer. You keep access to your visual data without manual saving steps.

## ⚙️ System Requirements

This application runs on standard Windows systems. You need the following:

* Windows 10 or Windows 11.
* A standard user account with permission to save files.
* Enough storage space to hold your image history.
* A stable internet connection for the first setup.

The software requires very little processing power. It waits in the background and only activates when you copy an image. It does not slow down your daily tasks.

## 💡 Using the Application

You do not need to change how you use your computer. Keep copying images as you normally do. Use the standard shortcut keys, such as Control + C, or right-click and select Copy.

Every time you copy an image, Image-Paster detects the change. It grabs the image data from your clipboard and writes a new file to your history folder. You can find these files later to view or share them.

The application manages the image files by date and time. This helps you find specific images even if you copied them weeks ago.

## 📂 Managing Image Storage

The app saves all images in a folder located in your Documents directory. You can navigate there at any time to move, delete, or rename your saved images.

If your folder becomes too large, you can delete old files without harming the program. The program does not rely on these specific files to operate. Consider clearing this folder once every few months to save disk space.
